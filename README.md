# Deep Learning


This repository contains a collection of code snippets and examples created for educational purposes, demonstrating key concepts and best practices in PyTorch. The code is annotated to explain the purpose and functionality of some key algorithms, neural architectures, and their use cases.

The `docs/` folder includes a PDF outlining a suggested curriculum for learning Deep Learning and the PyTorch framework. Alternatively, you can refer to the article on Medium: [Struggling with Deep Learning Frameworks? A Good Curriculum Is Likely What You Need](https://medium.com/@taha.rostami.darunkola/struggling-with-deep-learning-frameworks-a-good-curriculum-is-likely-what-you-need-ae2dbd89340a).
